1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?
Основное свойство, включающее CSS Grid — это `display: grid;`. 
Отличие от Flexbox: Flexbox — это одномерная модель компоновки (позволяет выстраивать элементы либо в строку, либо в колонку). CSS Grid — это двумерная модель, которая позволяет одновременно управлять и строками, и колонками, создавая полноценные сетки.

2. В чем разница между grid-template-columns и grid-auto-columns? Когда следует использовать каждое?
`grid-template-columns` задает явную сетку (те колонки, которые вы сами заранее прописали в коде). `grid-auto-columns` задает размер для неявных колонок, которые создаются браузером автоматически, если элементов в контейнере больше, чем предусмотрено явной сеткой. Использовать `grid-template` нужно для создания основного каркаса страницы, а `grid-auto` — когда количество элементов динамическое и заранее неизвестно.

3. Что делают функции repeat(), minmax() и auto-fit в определении grid-шаблона? Приведите примеры.
`repeat()` — повторяет заданное количество колонок или строк. Например, `repeat(4, 1fr)` создаст 4 одинаковые колонки.
`minmax()` — задает минимальный и максимальный размер для трека. Например, `minmax(200px, 1fr)` означает, что колонка не сожмется меньше 200px, но может растянуться на всю доступную ширину.
`auto-fit` — автоматически подстраивает количество колонок под ширину экрана, схлопывая пустые треки.
Пример: `grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));` — это создаст адаптивную сетку, где карточки будут сами переноситься на новую строку при сужении экрана.

4. Как работают именованные grid-области и какие преимущества они дают при создании макетов?
Именованные области задаются через свойство `grid-template-areas`. Вы рисуете карту макета в виде строк, где каждое слово — это имя области, а затем привязываете элементы через `grid-area`. 
Преимущество: Код становится визуально понятным. Глядя на CSS, сразу видно структуру страницы (где шапка, где подвал, где сайдбар), и легко менять порядок элементов, не переписывая HTML.

5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.
Линии сетки нумеруются с 1 (слева направо и сверху вниз), а также с -1 (с конца).
Свойства `grid-column` и `grid-row` принимают значения через слэш (начальная линия / конечная линия). 
Например, `grid-column: 1 / 3;` означает, что элемент начнется с 1-й вертикальной линии и растянется до 3-й (то есть займет 2 колонки).

6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?
`gap` (ранее `grid-gap`) задает расстояние между строками и колонками сетки. 
Чем лучше: Он создает отступы только между элементами, не добавляя лишних отступов по краям контейнера. Если использовать `margin`, вам пришлось бы отдельно прописывать `:last-child` и убирать крайние отступы вручную.

7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?
Они выравнивают содержимое внутри каждой ячейки сетки:
`justify-items` — выравнивает элементы по горизонтали (влево, вправо, по центру, stretch).
`align-items` — выравнивает элементы по вертикали (сверху, снизу, по центру, stretch).

8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?
Разница проявляется, когда элементов меньше, чем может поместиться в контейнере:
`auto-fill` создает пустые невидимые треки (колонки), сохраняя место под будущие элементы.
`auto-fit` схлопывает пустые треки до нуля, и существующие элементы растягиваются, заполняя все свободное пространство.

9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?
Создается сетка, где в кавычках прописывается каждая строка, а имена областей разделяются пробелами. Элементы привязываются через `grid-area: имя;`.
Правила именования:
Имя должно быть одним словом (без пробелов).
Область должна быть прямоугольной (нельзя, чтобы имя образовало букву «Г» или «П»).
Каждая строка матрицы должна содержать одинаковое количество колонок.

10. Двумерность: Позволяет управлять строками и колонками одновременно.
Чистота кода: Не нужно использовать хаки вроде `float` или `clearfix`, а также вложенные Flex-контейнеры для простых задач.
Независимость от HTML: Порядок элементов в сетке можно менять только средствами CSS (через `grid-area` или `order`), не меняя разметку.
Адаптивность: Встроенные функции (`minmax`, `auto-fit`) позволяют создавать отзывчивые сетки буквально одной строкой кода.
